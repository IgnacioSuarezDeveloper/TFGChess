## Instalacion y ejecucion (Windows)

    Desde la carpeta del proyecto, crea el entorno virtual si aun no existe y ejecuta:

    ```powershell
    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe main.py
    ```

    En VS Code, selecciona `.venv\Scripts\python.exe` como interprete de Python.
